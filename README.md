# fortuna_rs

This is an implementation of the Fortuna PRNG in Rust with ChaCha20.

## What is Fortuna

Fortuna is a CS-PRNG (*C*ryptographically *S*ecure *P*seudo *R*andom *N*umber *G*enerator) first published 2003 by Bruce Schneier and Niels Ferguson.
The CSPRNG is named after the Roman goddess of chance and is used in FreeBSDs _/dev/random_.
Readmore at: [Fortuna](https://en.wikipedia.org/wiki/Fortuna_(PRNG))
